Продолжаем задачу: довести боевой путь `ball_reel` до MVP и сделать **живой
прогон** — из фото лица получить видео, где ЭТОТ человек прыгает на гимнастическом
мяче, надёжно (с проверкой идентичности и ретраями). Весь генеративный стек — один
шлюз Pollinations (`gen.pollinations.ai`), ровно как в вакансии: Flux Kontext →
Seedance image-to-video, ArcFace для проверки лица.

Код — в приложенном `ball_reel.tar.gz`. Распакуй, работай в нём. Читай сначала
`POLLINATIONS_CONTRACT.md` (проверенный контракт API) и этот файл.

## Твои шаги (по порядку, дёшево → дорого)

1. **Предполёт без видео:** `python3 -m ball_reel.doctor` — теперь должно быть
   **5/5** (upload прошёл). Подтверди по факту, что `upload` вернул URL, и запиши
   в `POLLINATIONS_CONTRACT.md` реальные имена полей ответа (`url`/`id`).

2. **Видео (одна короткая генерация, тратит баланс):**
   `python3 -m ball_reel.doctor --video` — seedance-2.0, duration=2, из старт-кадра.
   Подтверди/зафиксируй:
   - тело ответа — mp4-байты напрямую или JSON с job/URL? Если JSON — допиши в
     `pollinations.video()` ветку поллинга-и-скачивания (в коде уже стоит явный
     `raise` с подсказкой на этот случай);
   - принял ли `image=` именно `media.pollinations.ai/{id}`;
   - сколько времени/во что обошлось (поле `usage`, если есть).
   Проверь заодно `GET /v1/models` → нет ли `/v1/videos/edits` (мультипарт-файл):
   если есть — это снимает нужду в media-хосте и для видео, поправь `video()`.

3. **ArcFace живьём:** `pip install insightface onnxruntime` (+ `ffmpeg` в PATH).
   `arcface_drift` тогда перестанет быть заглушкой. Если insightface не встаёт —
   не подменяй молча прокси-хэшем: у `produce` идентичность load-bearing, лучше
   явная ошибка, чем тихий даунгрейд.

4. **Боевой прогон на РЕАЛЬНОМ фото** (пользователь даст своё):
   `python3 -m ball_reel.produce --face моё_фото.jpg --attempts 4`
   Ожидаемая цепочка: images_edit(kontext) старт-кадр → ранний ArcFace-реджект,
   если это уже не тот человек → upload старт-кадра → video(seedance) → ffmpeg
   кадры → ArcFace + motion гейт → ретрай, пока не сойдётся, иначе лучший вариант
   с явной пометкой NOT PASSING. Прогони, покажи `produce_report.json` и клип.

5. Живые прогоны почти наверняка вскроют 2–3 расхождения формы API (так всегда с
   живым API против доков). Правь `pollinations.py` по факту, каждое расхождение
   дописывай в `POLLINATIONS_CONTRACT.md` с пометкой `[проверено live]`.

## Грабли (не наступай повторно)

- `image=` (и, вероятно, видео) — сервер Pollinations **сам фетчит URL** со своей
  стороны. Нужен реально публичный URL (`media.pollinations.ai/{id}`), НЕ локальный
  путь и НЕ самоссылка на `gen.pollinations.ai` (та отдаёт 522 при серверном фетче).
  Поэтому старт-кадр — через `images_edit` (мультипарт), а для видео — через `upload`.
- Ключ **без права `account:usage`** → баланс не прочитать (`/account/*` = 403).
  Не делай чтение баланса предполётом; предполёт — это `doctor`, т.е. генерация.
- Прокси: `HTTPS_PROXY` и CA-бандл уже настроены, `requests` ходит сам. При 403 от
  прокси на хост — **не обходить** (это политика), см. `/root/.ccr/README.md`.
- Офлайн-тесты (`python3 -m unittest discover -s ball_reel/tests -p 'test_*.py'`)
  должны оставаться зелёными (11, из них 5 arcface-math скипаются без numpy). Держи
  их зелёными: `pollinations`/`insightface` импортируются лениво.
- Дисциплина (из CLAUDE.md пользователя): живой смок обязателен к сдаче; «блокеров
  нет» без прогона не принимается; непроверенное держи помеченным непроверенным.

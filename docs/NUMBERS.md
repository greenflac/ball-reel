# Числа набора: одно место, одна команда

Здесь и только здесь стоит текущий размер тестового набора. Остальные документы
на него ссылаются, а не повторяют — потому что повторённое число устаревает
молча, и в этом репозитории это уже случилось шесть раз подряд.

## Текущее состояние

| Что | Значение | Чем получено |
|---|---|---|
| Офлайн-тесты | **1372**, `OK (skipped=7)`, ~56 с | `python3 -m unittest discover -s ball_reel/tests -t . -p 'test_*.py'` |
| Мутации порогов | **119**, выживших нет | `python3 -m ball_reel.codeaudit` |
| Пропусков в клоне | **7** — столько же, сколько в дереве | `python3 -m ball_reel.codeaudit` (строка «клон из индекса») |
| Файлов с тестами | **49** | `git ls-files ball_reel/tests \| wc -l` |
| Пропусков в копии для мутаций | **7** — столько же | `python3 -m ball_reel.codeaudit` (строка «копия для мутаций») |

Замер: 2026-08-15, Linux, CPU.

Число мутаций дополнительно сверяется тестом: `len(codeaudit.MUTATIONS)` должно
совпадать с тем, что написано здесь и во всех остальных документах. Число
тестов проверить статически нельзя — его можно только прогнать, — поэтому оно
живёт в одном файле, и тест запрещает называть его где-либо ещё.

## Почему семь пропусков — это не дефект

Ни один из семи не про недостающие данные. Все семь — про то, что окружение
**исправно**, и путь отказа поэтому не срабатывает:

| Сколько | Причина |
|---|---|
| 2 | живой прогон CLIP выключен: нужен `BALL_REEL_SEMANTIC_LIVE=1` |
| 1 | живой прогон семантики под тем же флагом |
| 1 | ключ на месте — отказу неоткуда взяться |
| 1 | веса на месте — лечению неоткуда взяться |
| 1 | веса лица на месте |
| 1 | torch собран с CUDA 13.0 — CPU-сборку не воспроизвести |

## Что здесь было раньше и почему это записано

Числа расходились по документам так:

Перечёркнутое — то, что документ утверждал как текущее; стёрто из документов,
но не отсюда.

| Документ | Утверждало | |
|---|---|---|
| `README.md` | ~~`Ran 1336 tests`~~ | ближе всех |
| `docs/NEW_SESSION_PROMPT.md` | ~~1283 теста~~, 119 мутаций | мутации верны |
| `docs/LAUNCH.md` | ~~1192 теста, 118 порогов~~ | |
| `docs/GUIDE.md` | ~~824 теста, 77 мутаций~~ — и ~~56 порогов~~ двумя абзацами выше | сам себе противоречил |
| `docs/REFERENCE.md` | ~~801 тест, 27 файлов, 56 порогов~~ | файлов на деле 49 |
| `docs/GPU_RUNBOOK.md` | ~~801 тест, 56 мутаций~~ | |
| `docs/TEST_KIT.md` | ~~`Ran 801 tests in 88s`~~ | |
| `docs/DEMO_RUNBOOK.md` | ~~527~~ | |

Разброс по тестам — от 527 до 1336 при действительных 1372, по мутациям — от 56
до 119 при действительных 119. Это не небрежность в оформлении: по такому документу
планируют смену. Ровно этот сорт расхождения описан в `CLAUDE.md` как причина
сверять хэндоф прогоном, а не верить ему.

Исторические упоминания в тех же документах (`~~801~~`, «здесь стояло 249»)
**оставлены намеренно** — история находок часть ценности репозитория. Стёрты
только утверждения, поданные как текущие.

# Оглавление документов

По одной строке на документ: что внутри и когда снят. Дата — дата последнего
коммита файла (`git log -1 --format=%ad`), а не дата, написанная внутри текста.

**Как читать этот каталог.** Документы делятся на два слоя. Слой **ФОРКА**
(`FORK_*`, 17–22.08.2026) — текущая работа: продукт «фото + драйвинг + стиль ->
ролик» на чужой видеомодели. Слой **ЛОКАЛЬНОГО ГРАФА** (без префикса,
12–17.08.2026) — более ранняя ветка проекта: своя генерация на своей карте
(SD1.5 + AnimateDiff + LoRA, потом Wan 2.2 Animate в ComfyUI). Второй слой
из продукта не выкинут, но сегодня по нему не работают, и его числа сняты на
другом материале. При расхождении между слоями главнее слой форка, потому что
он свежее.

**Устаревшее внутри свежих документов — три места, найденные при сборке этого
оглавления.** Все три написаны утром 22.08 и опровергнуты к вечеру того же дня;
исправлены они не были, поэтому названы здесь:

1. `FORK_ПРОДУКТ.md` (коммит 10:07) наверху: «ни одного ролика не
   сгенерировано». К 12:11 роликов пять (`FORK_E2E_МОДЕЛИ.md`).
2. `FORK_СТИЛИ.md` (11:43) наверху: «стиль ни разу не доехал до ролика».
   К 16:44 доехал: `work/e2e_final.mp4` собран со стилевым референсом.
3. `FORK_БЛОКЕРЫ.md` (10:15) держит блокером №1 «баланс fal.ai = 0.0», а в
   `FORK_E2E_МОДЕЛИ.md` баланс 8.8884925 и пять оплаченных заказов.

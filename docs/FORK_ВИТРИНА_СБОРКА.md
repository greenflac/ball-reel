## Витрина

Три панели 9:16 в ряд, 1422x892, ровно 10.0 секунды, звук из готового ролика:

| панель | источник |
|---|---|
| фото | `assets/fork_client_selfie_f.png` (1536x2752) |
| драйвинг | `work/six/icecream/window.mp4` (576x1024, 300 кадров) |
| результат | `work/six/icecream/final.mp4` (720x1280, 300 кадров, AAC) |

Шаблон выбран владельцем: «самый неплохой с мороженым».

Витрина показывает **вход и выход**, а не вход и вход: раньше на первом экране
стояли фото клиента и эстетика шаблона, то есть две картинки, которые
пользователь никогда не увидит. Теперь слева то, что он загружает, справа то,
что он получает, посередине — единственный вход, который покупается.

GIF (680x426, 11 к/с, 110 кадров, 3.4 МБ) нужен потому, что GitHub не
проигрывает mp4 по относительной ссылке в README. Ссылка на mp4 стоит рядом:
звук есть только там.

## PDF

Рендер — Chromium headless из `docs/deck/lipsync.html`, A4, поля 13x12 мм.

```
chrome --headless --disable-gpu --no-sandbox --hide-scrollbars \
       --virtual-time-budget=15000 --run-all-compositor-stages-before-draw \
       --no-pdf-header-footer --print-to-pdf=... file://...
```

Три дефекта, найденные только на отрендеренном PDF, а не в HTML:

1. **Шрифты не доехали.** Chromium в этой среде не доверяет CA прокси и роняет
   TLS до `fonts.googleapis.com`; первый прогон вышел набранным Liberation Sans
   вместо Unbounded/Golos Text/JetBrains Mono. Прокси НЕ обходился: `curl` через
   тот же прокси отвечает 200, поэтому 15 файлов шрифта (379 328 Б) скачаны им и
   вшиты в CSS как `data:` URI. ИЗМЕРЕНО: в PDF вшиты сами гарнитуры.
2. **Мохибейк.** В `lipsync.html` нет `<meta charset>` — его подставляла обёртка
   артефакта. Без неё Chromium читает файл как latin-1, и длинные тире выходят
   как `â€"`. ИЗМЕРЕНО по извлечённому тексту: было `â€` в тексте, стало 0
   вхождений при 21 (ru) и 12 (en) длинных тире.
3. **Колонтитулы.** Дата, `file://`-путь и номер страницы печатались.
   `--print-to-pdf-no-header` в этой сборке Chromium не действует; действует
   `--no-pdf-header-footer`.

ВЫБРАНО (владельцем не проверялось): A4 книжной ориентации, а не слайды.
Документ читается сверху вниз и содержит таблицы — на слайдах 16:9 они бы
резались.

Обе версии по 6 страниц. Язык переключается атрибутом `data-lang` на корне
перед печатью, разметка одна: два файла разъехались бы на первой же правке.

П3: страницы 1, 2, 3, 5 русской версии открыты картинками. Разрывы падают между
блоками, таблица экономики и плитки чисел не разрезаны. Один разрыв оставляет
четверть страницы пустой — между четвёртым и пятым шаблоном семейства; это цена
правила «карточка шаблона не режется», и она принята.

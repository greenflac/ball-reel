# Слой стилей: адаптер из vertical-creative-eval

## НЕПРОВЕРЕНО — наверх (Ц4)

1. **Стиль ни разу не доехал до ролика.** Всё ниже — про то, чем стиль
   ОПИСЫВАЕТСЯ и ИЗМЕРЯЕТСЯ, а не про то, что модель ему подчиняется.
2. **Ось похожести стиля — ГРУБЫЙ ПРОКСИ ПО ЦВЕТУ И ФАКТУРЕ, а не эмбеддинг.**
   Модуль требует повторять эту оговорку везде, где приводится его число, и
   здесь она повторена. Это не CLIP и не DINO.

## Откуда берём

`greenflac/vertical-creative-eval`, склонирован read-only.
**Лицензия проверена до встраивания (Ц5):** код MIT; словарь стилей автор
перелицензировал под MIT; `references/` — производные данные из чужой галереи
`aidsgn.ru`, прав на неё проект не заявляет и изображений не хранит. Значит
код и словарь встраивать можно, галерею перераспространять нельзя.

Работает на том же `POLLINATIONS_API_KEY`, что уже стоит в окружении.

## Что оттуда берётся

| | |
|---|---|
| `style.style_card(path)` | картинка -> карточка стиля: цвета, тональность, насыщенность, фактура |
| `style.similarity`, `palette_conformance` | насколько кадр попал в заданный стиль |
| `references/` — **522 карточки** | готовый корпус стилей, 10 категорий |
| словарь | **47 цветов**, 3 тональности (light/mid/dark), 3 насыщенности, 2 фактуры |

Распределение корпуса: тональность light 72 / mid 223 / dark 227;
насыщенность muted 74 / moderate 224 / saturated 224.

## ПРОВЕРЕНО НА НАШЕМ МАТЕРИАЛЕ, 22.08

    драйвинг, кадр 150      {black, beige, camel}      mid   moderate  гладкая
    выход fal, кадр 50      {charcoal, sand, camel}    mid   moderate  гладкая
    рефка клиента           {black, white, gold}       mid   moderate  зерно
    тестовое фото slim      {silver, light grey, stone} light muted    гладкая

    ПОХОЖЕСТЬ (прокси, не эмбеддинг):
      вход против выхода                0.7553 | конформность палитры 0.7205
      вход против рефки клиента         0.6156 | 0.7075
      НЕГАТИВНЫЙ КОНТРОЛЬ, сам с собой  1.0000 | 1.0000   <- прибор обязан дать 1
      пол шкалы SCORE_FLOOR             0.0701
      потолок при слепой палитре        0.4273

Прибор различает: одно и то же даёт 1.0, вход против выхода 0.7553, вход
против чужой сцены 0.6156. Негативный контроль отработал.

**Важное наблюдение:** выход fal сохранил тональность и насыщенность входа
(mid / moderate), но сдвинул цвета (black -> charcoal, beige -> sand). То есть
модель стиль НЕ ДЕРЖИТ жёстко, и место для стилевого промта физически есть.

## Чего в корпусе НЕТ и почему это работа, а не находка

**Текста промтов в `references/` нет** — только «скелет»: число слов, число
клауз, соотношение сторон, флаги. Это сделано намеренно, из-за происхождения
галереи. Значит адаптер обязан **порождать текст промта из карточки**, а не
копировать чужой. Это и есть предмет работы:

    карточка стиля {цвета, тональность, насыщенность, фактура}
        -> фраза промта для видеомодели
        -> замер: доехало ли (similarity/conformance против референса)
        -> негативный контроль: тот же ролик с пустым промтом

Без последних двух строк стиль «заведён» на словах: восемь стилей, которые
ничего не делают, выглядят точно так же, как восемь работающих.

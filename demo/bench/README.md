# Стенд выбора окна лупа

Здесь лежат данные, на которых проверяются числа в шапках
`ball_reel/tests/test_loop_window.py` и `ball_reel/tests/test_loop_pose.py`.
Стенд нужен потому, что до него эти тесты ходили в каталог `ref_frames`,
которого в git нет ни одним файлом: у автора он лежал локально и тесты были
зелёными, а в клоне молча пропускались. Пропусков в клоне было 22 против 7 в
рабочем дереве — пятнадцать сторожей спали, и увидеть это можно было только по
числу пропусков.

## Что здесь

| Файл | Что это | Размер |
|---|---|---|
| `driving/0000..0095.jpg` | 96 кадров драйвинга, ширина 240 px | 1.46 МБ |
| `pose_96.json` | скелеты тех же 96 кадров, снятые с **полного** размера | 0.08 МБ |

Исходник — 96 кадров 720×1278 (67 МБ), в репозиторий не кладётся.

## Почему кадры уменьшены, а скелеты — нет

Пиксельная мера смотрит на **отношение** стыка к худшему окну, и уменьшение его
почти не трогает:

| | окно | стык | худшее | выигрыш |
|---|---|---|---|---|
| 720×1278 | 66 | 1.245 | 6.568 | 5.28× |
| 240×426 | 66 | 1.227 | 6.394 | 5.21× |

Выбрано то же окно, числа разошлись на 1.5%.

С позой так **не выходит** — это отдельная находка, записанная числом:

| ширина кадра | выбранное окно |
|---|---|
| 720 px | 52 |
| 360 px | 64 |
| 240 px | **35** — медленный участок, против которого писан критерий |
| 180 px | 66 |

Согласия нет ни у одной пары. Причина не в критерии, а в дрожании MediaPipe: на
мелком кадре шум сустава сравним с шагом движения, и локальная медиана —
знаменатель критерия — плывёт вместе с ним. **Следствие для продукта:** позы для
выбора окна снимаются с исходного размера, а не с рабочего.

Поэтому скелеты положены готовой фикстурой: тест судит выбор окна, а не
экстрактор, и должен получать тот же вход, что и продукт. Экстрактор сторожится
отдельно — классом `ResolutionChangesTheChoice`, который снимает позы с
уменьшённых кадров и проверяет, что цена уменьшения всё ещё та самая.

Побочный выигрыш: выбор окна теперь проверяется в любом клоне, а не только там,
где скачались веса MediaPipe.

## Пересчитать числа

```bash
python3 -c "import glob;from ball_reel import motion;\
g=motion.best_loop_window(sorted(glob.glob('demo/bench/driving/*.jpg')),size=16);\
print(g['start'],g['ratio'],g['worst_ratio'])"

python3 -c "import json;from ball_reel import motion;\
d=json.load(open('demo/bench/pose_96.json',encoding='utf-8'));\
print(motion.best_loop_window_pose([{k:tuple(v) for k,v in f.items()} \
for f in d['frames']],size=16)['note'])"
```

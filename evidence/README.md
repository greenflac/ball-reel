# Доказательства живых прогонов

Здесь лежат артефакты **настоящих** запусков через шлюз, а не примеры. Оба
несошедшихся — и это не отбор неудач, а наоборот: провал, записанный с
причиной, доказывает, что гейт работает, гораздо убедительнее, чем удачный
кадр, про который нельзя сказать, повезло нам или система его удержала.

Каталог отслеживается git намеренно. Раньше и `wiretest/`, и `chain_out/`
целиком лежали в `.gitignore` — то есть аудитор, клонирующий репозиторий,
не увидел бы ни одного доказательства вообще.

## `produce_report_failed_gate.json`

Полный прогон `produce` через Pollinations. Гейт **не пропустил результат**:

> no attempt held identity across a moving clip in 1 tries. Best median drift
> 1.0 (bar 0.35). Returning the best attempt, flagged NOT passing — do not
> ship blind.

Что здесь важно и что стоит прочитать целиком:

* `passed: false` — пайплайн отдал клип, но **пометил его негодным**. Он не
  прячет провал и не выдаёт лучшую попытку за успех;
* дрейф идентичности 1.0 при пороге 0.35 — то есть на клипе не тот человек.
  Это ровно тот отказ, ради которого написан ArcFace-гейт;
* «1 tries» — прогон был на одной попытке, ретраи не отрабатывали. Число
  попыток честно записано, чтобы результат нельзя было принять за статистику.

## `chain_keyframes_api_400.json`

Прогон цепочки кейфреймов, где **шлюз отказал**: HTTP 400 от провайдера
картинок (`OpenRouter Gemini image generation request failed`). Четыре узла,
принято ноль.

Это доказательство второго рода — не «наш гейт отбраковал», а «внешний API
упал, и пайплайн записал это по узлам, с причиной в каждом», вместо того чтобы
уронить прогон трейсбеком. Для стенда, который живёт на чужом API, поведение
при отказе API — часть контракта.

## Провенанс, который надо знать при чтении

Имена кадров внутри `produce_report_failed_gate.json` двузначные
(`01.png` … `14.png`). Это **до** исправления шаблона имён: тогда кадры
извлекались как `%02d`, и со сотого кадра лексикографическая сортировка
ломалась. Дефект найден и исправлен позже (`FRAME_PATTERN = "%04d.png"`),
на этом клипе он не срабатывал — кадров было меньше сотни.

Оставлено как есть намеренно. Артефакт живого прогона — это запись того, что
было, а не того, как хотелось бы. Переименовать его задним числом значило бы
подделать доказательство.
